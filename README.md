# InsightIQ.2

InsightIQ.2 makes data analysis interactive, dynamic, and beginner-friendly.

## Problem Being Solved

Most dashboards are built for one fixed dataset schema. When columns or structure change, the dashboard often breaks or needs manual rebuilding.

InsightIQ.2 is designed to avoid that by dynamically adapting to uploaded CSV data.

## Core Workflow

1. **Upload a CSV file**
2. **Automatically understand dataset structure** (column names, data types, missing values, basic distributions)
3. **Generate analytics and insights automatically** without hardcoding for one specific dataset

## Project Goal

Provide a reusable, schema-flexible analytics experience where users can upload different CSV files and still receive meaningful charts, summaries, and insights.
